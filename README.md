# AutoEdit

Android-приложение, которое само собирает динамичный эдит из твоих видео и трека:
слушает музыку, находит биты и дроп, режет материал по долям и вешает эффекты
(зум-панчи, тряска, RGB-сплит, шлейфы, стробы, вип-переходы, глитчи, «вылет перса»).

## Как это работает

1. **Аудио-анализ** (`core/BeatDetector.kt`) — STFT → спектральный поток → автокорреляция темпа
   → сетка битов динамическим программированием (метод Эллиса) → разметка интенсивности и поиск дропа.
2. **Видео-анализ** (`engine/MediaAnalyzers.kt`) — выборка кадров, оценка движения,
   детализации и экспозиции; нарезка исходника на сегменты с рейтингом.
3. **Планировщик** (`core/EditPlanner.kt`) — раскладывает шоты по битам: длина реза зависит
   от энергии секции, на дропе — строб-очереди и стоп-кадры, перед дропом — слоу-мо с разгоном.
4. **Рендер** (`engine/EditRenderer.kt`) — MediaCodec декодирует исходники в OpenGL-текстуры,
   цепочка шейдеров накладывает эффекты, H.264-кодировщик пишет результат, музыка
   перекодируется в AAC и склеивается с видео.

Никаких сторонних медиа-библиотек: только Android SDK, OpenGL ES 2.0 и Compose.

## Сборка

```bash
./gradlew assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.
Каждый push собирает APK в GitHub Actions и публикует его в релизе.
